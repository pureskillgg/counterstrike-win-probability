# CS2 / esports round and match win-probability: model choice literature

Compiled 2026-10-12 for Meridian project fa6f6e09-513d-4788-9db5-43123df4ce0f.
Scope: how round or match win-probability (WP) models have been built and evaluated in FPS and team esports, CS:GO/CS2 first, then Valorant, Dota 2, League of Legends.

## Short answers to the four questions

1. **Model families.** Round-level CS:GO/CS2 WP is mostly boosted trees (XGBoost best in the 2020 CS:GO study and the 2025 CoG study), with logistic regression as the calibrated baseline. Neural nets are close to boosted trees: in the 2021 CS:GO paper a NN edged XGBoost on log loss (0.736 vs 0.739). The CS2 README claims nine architectures tie in CV (unverified). ESTA's benchmark results were not read. Markov-style WP: the only one found is cricket (Mishra 2026). No esports hazard model found.
2. **Features.** Alive/remaining players per side, equipment value and economy (money, loss bonus, buy type), HP, bomb planted and site, distance to bomb site, time since round start or last phase change, spatial control (Voronoi, line of sight). Time is almost always included.
3. **Metrics.** Accuracy is still common (LoL 2023; Valorant 2025 at 60.61%). Log loss, Brier and calibration curves are the standard in the stronger CS:GO papers (Xenopoulos et al. 2020, ESTA, CS2 README). Choi et al. (2023) argue accuracy cannot evaluate a probability and propose a Balance score.
4. **Splits.** Chronological (Xenopoulos 2020; Xenopoulos 2021) or grouped-by-match (Choi 2023; CS2 README 5-fold GroupKFold) splits are the clean ones. ESTA's benchmark samples one game state per round per demo and then splits the states 70/10/20 at random, which is not grouped by match, so it carries round-level leakage risk. The LoL 2023 paper uses cross-validation with grouping not stated. The Valorant Seq2Seq split is not read.

## Leakage and evaluation notes

- **Round-level random splits leak.** States from the same match share rosters, map and team identity, so a random split across rounds lets the model memorise matches. ESTA's split does this. Use grouped-by-match CV or chronological splits (papers 1, 2, 4, and the CS2 README do this).
- **Accuracy is not a probability metric** (Choi 2023). Report log loss, Brier and a calibration measure (ECE with a bin count, or calibration curves), and check calibration separately at each game time.
- **Time-updating WP needs time-sliced evaluation.** Papers 1, 4 and 6 report by time point. Log loss falls as the round nears its end, so report per-phase results (pre-plant, post-plant).
- **Sample units differ.** Paper 2 predicts game outcome from round-start state; paper 7 predicts match outcome from the first 12 rounds; ESTA and paper 1 predict round outcome from game states. Compare only like with like.
