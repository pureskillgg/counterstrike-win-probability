# X10: calibration post-processing of the GPU XGBoost baseline

Script: scripts/exp/X10_calib.py. Log: logs/exp/X10_calib.log (final run).
Model: baseline XGBoost params on CUDA (RTX 3080), monotone vector as baseline, early stopping 100 on val.
best_iteration = 280 (CPU baseline: 301). Predictions use iteration_range=(0, 281).

Calibration fitted on VALIDATION predictions only; applied to test.
- (a) single temperature on logit: T = 0.9761
- (b) isotonic regression (out_of_bounds=clip, y bounds 1e-6)
- (c) per-time-bin temperature on seconds_since_round_live: 0-20 T=0.9761, 20-40 T=0.9835, 40-60 T=0.9740, 60+ T=0.9688

Middle band (raw 0.45-0.65 on test, n=143,316): mean(pred) - mean(y) = +0.0114 raw, +0.0122 temp, +0.0088 iso, +0.0122 bin-temp.
The 3-5 point over-prediction was NOT reproduced at this pooled-band level on test (about 1.1 points). Not checked: sub-bins inside the band, or validation band gap.

Per-time-bin test logloss, raw vs bin-temp: differences are +0.00002 to +0.00005 (no gain).

Conclusion: no recalibration worth keeping. Temperature and per-bin temperature are within noise and slightly worse on test. Isotonic is significantly worse. The raw GPU model is already well calibrated (ECE10 0.0097).

Failures and caveats:
- First run exited with code 127 right after loading data (cause not identified). Second run finished training but hit a host MemoryError (1.24 MiB allocation) while other jobs held RAM and commit. Fixed by freeing the train arrays and booster after prediction. Third run succeeded.
- Predictions were called with numpy input on a CUDA booster, so XGBoost printed a DMatrix-fallback warning. Predictions are unaffected, only speed/memory.
- Calibration maps were fitted on validation, which was also used for early stopping, so the val numbers are slightly optimistic. Test was not used for any fitting.
- Helper E.report appended 4 rows to data/viz/pt_results.jsonl (X10_raw_gpu, X10_temp, X10_iso, X10_bintemp). The paired-vs-GPU runs used save=False.
- Saved float64 predictions: data/viz/pt_preds/X10_{val,test}.npy (raw), X10_temp_*, X10_iso_*, X10_bintemp_*.
