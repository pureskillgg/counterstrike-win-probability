# X9: weapon data, patch and era investigation

No GPU used (task is CPU-only). Scripts: `scripts/exp/X9_header.py`, `X9_schema.py`, `X9_weapon_stats.py`. Log: `logs/exp/X9_weapon_stats.log`. No model was trained and no predictions were saved, so `E.report` was not called.

## 1. Weapon properties, version fields, price

- No table of weapon damage, price or rate of fire in the tomes or the dictionary. No weapon property enumeration was captured in `notes/spec` (the docs enums page is referenced; weapon codes are not expanded there).
- No game version or patch field. Header fields that bear on version: `build_num`, `demo_version_name`, `demo_version_guid`, `game_directory` (e.g. `csgo_v2000922`), `server_name`.
- `build_num`: 2024 tome = {9842, 9961}; 2026 tome = {10896, 10924}. Build values are not mapped to patch dates here.
- `player_status` is not a channel in either tome (absent from both `basic_*` lists). The dictionary lists `current_equipment_cost`, `freezetime_end_equipment_cost`, `round_start_equipment_cost`: player-level money or equipment value, not per-weapon price.
- Weapon names are strings in `weapon_name` on `weapon_fire`, `player_death`, `player_hurt` (e.g. `ak47`, `m4a1_silencer`, `usp_silencer`, `galilar`). Names are consistent across eras.

## 2. Dates and CS:GO

- 2024 tome `match_date`: 2023-12-28T18:34:26Z to 2024-02-25T23:29:47Z. 4,435 header rows, 4,434 distinct `match_key` in `round_start`.
- 2026 tome `match_date`: 2026-09-18T08:53:34Z to 2026-10-08T23:10:52Z. 1,752 header rows.
- Caveat from the repo digest: `match_date` is the processing date for hand-uploaded matches.
- No CS:GO-era match found. All 4,435 + 1,752 headers have `server_name` starting "Valve Counter-Strike 2" or "FACEIT", none contain "Global Offensive". The 2024 `game_directory` values include `csgo_v2000xxx` (4,433 of 4,435), which is the internal folder name, not an era marker.
- Repo docs: CS:GO data exists in older revisions (collection from 2021-12-01); csgo-dsdk test fixtures are 2022-05-15 CS:GO-era. Neither is in these tomes.

## Caveats

- `player_hurt` has `hit_box_code`, no named hit-group field. Head-hit % uses `hit_box_code == 1` as a proxy. Kill HS % uses the documented `player_death.is_headshot`.
- `player_hurt` has no `m4a1_silencer` or `usp_silencer` rows (damage is attributed under other names), so dmg and head-hit are n/a for those two.
- About 86 kills in 2024 fell outside `round_start` match keys and were dropped (top-10 list shows 167,432 for ak47, table shows 167,346).
- Team-kill filter keeps rows with null team codes.
- The kills/shot difference between eras is not separable from: changed match population (FACEIT and hand-uploaded matches are in 2026), the 2024-02-12 and 2026 pipeline rebuilds (round_end, player_info), and the 2026 reload and balance patches. The data cannot attribute the change to any patch.
- Patch dates above are unverified (snippets only).
