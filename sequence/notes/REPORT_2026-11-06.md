# CS2 round win-probability: sequence models vs XGBoost, report as of 6 Nov 2026

Working report. Results are from the Meridian pins and the network-volume metrics. Every log-loss figure is validation, final-step, on 1,169 matches (1,515,228 seconds), unless marked otherwise. The XGBoost split counts 1,168 validation matches for the same seconds; the one-match gap has not been traced. The holdout figure is the single pinned read and is not used for any choice.

## 1. Summary

- **On the GDT-trained runs, no sequence model beats the GRU control on GDT.** No arm passes the pinned bar. On the log-loss-trained runs, xLSTM sigmoid-gate passed the GDT bar (section 3.4), but no arm passes the round-2 every-seed rule (section 3.5).
- **The one arm that passed earlier was on a different training objective.** Pin c807884d selected xLSTM sigmoid by scoring the log-loss-trained models on GDT. The GDT-trained models, scored the same way, don't reproduce that result.
- **XGBoost (the final 83-input model) is in the same range as the GRU** on validation log loss. The GRU has beaten the 57-input XGBoost on validation on every seed (pin 921fa3dd).
- **No holdout read has been done for any sequence model.** There's no candidate under the pinned rules, so the holdout read (pin 0d97f8f6) is on hold.
- **Weights were retrained** so that the GDT-trained models could be exported. The retrain has finished (section 5).

## 2. What was compared

- **Models:** XGBoost (final 83-input model), and sequence models: GRU (control), LSTM, TCN, transformer (two sizes), MinGRU, MinLSTM, LRU, RWKV-7, Mamba-2, Griffin, Gated DeltaNet (two variants), xLSTM (loop, closed-form, two-head, 7B-style block, sigmoid-gate). The architecture rationale is in `notes/architectures/ARCHITECTURES.md`.
- **Inputs:** the same per-second state, loadout and 24 train-only position features for every sequence arm (pins 6fb5578a, 66bca815).
- **Protocol:** validation only for every choice (pin 64b9d52d); five seeds for the arms in the round-2 comparison, and one seed for the rest. Paired comparisons against the GRU control of the same seed; intervals from match-cluster bootstrap, 1,000 resamples, RNG seed 0.
- **Objective:** log loss for the first set of runs. GDT-equivalent training for the second set (pin 064d46c76, amendment 079f7189, per the user's report of Dr Freeman's instruction; the user confirmed the objective on 7 Nov 2026).

### 3.4 Earlier selection on the log-loss-trained models (pin c807884d)

Scoring the log-loss-trained models with the same GDT grader selected xLSTM sigmoid-gate: pooled +0.00131, interval +0.00042 to +0.00230, situation-weighted +0.00047. That result is what pin 0d97f8f6 names as the candidate. The GDT-trained scoring above doesn't reproduce it, so that candidate should be treated as unconfirmed.

### 3.5 Round-2 log-loss rule (pin 31f6825b, paired test)

Against the GRU control, every seed of each arm must have an upper bound below zero, and the pooled gain must be at least 0.0005. The pooled gains were −0.00094 (closed-form xLSTM), −0.00112 (7B-style block) and −0.00072 (sigmoid-gate), but each arm had at least one seed whose upper bound was above zero. So no candidate was adopted under the log-loss rule either.

### 3.6 XGBoost (final 83-input model)

- **Validation log loss, three seeds:** 0.450228, 0.450305, 0.450223 (mean about 0.45025). Pin 1b7c86fd.
- **Reproduced from saved predictions:** seed 0 gives 0.45021, within 2e-5 of the pinned value.
- **Holdout, October 26–31, 3,315 matches:** seed-mean log loss 0.452295, interval 0.449288 to 0.454983. This is the single pinned read (pin 56316f69). It was taken before the GDT decision and isn't used for any choice.
- **GDT score (validation proxy, seed 0 only):** against the GRU control at seed 0, the XGBoost GDT difference is −0.00071 (95% interval −0.00269 to +0.00131), situation-weighted −0.00023. Its GDT against the lookup table is 0.02549, against 0.02620 for the GRU at seed 0. XGBoost and the GRU are not distinguishable on GDT.

### 3.7 Reference models

- **57-input XGBoost (v6):** frozen-test log loss 0.456411 on 3,059 matches (19–20 Oct package). The intern's GDT on the October 14–25 test days is 0.0180. That's on a different window from our validation set, so the two aren't directly comparable.

## 4. Caveats

1. **GDT population.** Our GDT numbers use a proxy population: 297 validation matches uploaded September 1 to October 8. The intern's test window (October 14–25) is locked. So our GDT scores are a validation proxy, not the intern's test score.
2. **Seed noise.** Seed-to-seed spread is about 0.0005 in log loss. Most arm-to-arm gaps are of that size.
3. **Single holdout read.** The XGBoost holdout read is one pinned read. Nothing else has been read on the holdout.
4. **Training objective.** The GDT-trained runs follow the user's report of Dr Freeman's instruction. The user has confirmed the objective (7 Nov 2026).
5. **Deviation.** The capacity transformer ran without the 500-step warm-up its pin specified. That result is recorded as run.
6. **Weights.** Earlier runs didn't save weights. The current retrain does; 43 of 47 runs reproduce the earlier validation log loss within 1e-4 (section 5).
